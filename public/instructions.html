Beam Simulation — Instructions

Background

This tool simulates the acoustic beam produced by an ultrasound-style phased-array transducer. Sound waves emitted from individual elements combine constructively and destructively as they travel through the field, producing a pattern of peaks and nulls in intensity. The simulation computes this interference pattern across a two-dimensional field (depth vs. lateral width) and displays it as a grayscale image, where brighter pixels indicate higher beam power.

Optionally, the transducer elements can be steered (angled), focused to a point, or spaced apart with gaps to model more realistic array configurations.

Usage

Fill in the values in the Simulation, Transducer, and Display profile groups, then click Run Simulation. The status line shows progress while the field is computed. When finished, the beam power image is displayed on the right, normalized so the brightest point in the field is white.

Check Beam profile to overlay a red line at a chosen depth and show a line graph, titled "Beam amplitude profile," of the beam amplitude across the width of the field at that depth. Changing the Distance value moves the line and updates the graph; unchecking the box hides both.

Variables

Depth (cm) — Simulation
Total distance from the transducer to the far edge of the simulated field.
Width (cm) — Simulation
Total lateral width of the simulated field, centered on the transducer.
Frequency (MHz) — Transducer
Operating frequency of the transducer. Higher frequencies produce shorter wavelengths and finer detail.
Width (cm) — Transducer
Physical width of the transducer aperture (the array of emitting elements).
Focus (cm)
Distance at which the beam is focused to a point. A value of 0 disables focusing, producing an unfocused (planar) beam.
Angle (deg)
Steering angle of the beam relative to straight ahead. Negative and positive values steer left/right.
Emitters (count)
Number of individual elements making up the transducer array.
Element Gap
Size of the gap between elements, as a fraction of the element pitch, used to model spaced (non-continuous) transducer arrays. "None" models a continuous transducer with no gaps.
Beam profile / Distance (cm) — Display profile
Enables the red highlight line and amplitude graph at a specific depth, from just past the transducer up to the simulation depth.
